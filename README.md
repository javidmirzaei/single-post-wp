# پلاگین Beautiful Post

طراحی حرفه‌ای و جذاب برای صفحه تک مقاله وردپرس

## 🎨 ویژگی‌ها

### ✨ عکس شاخص تمام صفحه (Hero Section)
- نمایش تصویر شاخص به صورت تمام صفحه با overlay زیبا
- عنوان مقاله روی تصویر با افکت سایه
- طراحی واکنش‌گرا برای موبایل و تبلت

### 📊 متا اطلاعات زیبا
- تاریخ انتشار با اعداد فارسی
- دسته‌بندی مقاله
- نویسنده مقاله
- تعداد نظرات
- آیکون‌های SVG زیبا

### 👤 باکس نویسنده
- نمایش اطلاعات کامل نویسنده
- آواتار نویسنده
- بیوگرافی نویسنده
- لینک به صفحه آرشیو مقالات نویسنده
- طراحی با گرادیانت جذاب
- **قابل غیرفعال‌سازی از تنظیمات**

### 🔗 دکمه‌های اشتراک‌گذاری
شبکه‌های اجتماعی پشتیبانی شده:
- تلگرام
- واتساپ
- توییتر
- لینکدین

**قابلیت‌ها:**
- فعال/غیرفعال کردن کل بخش از تنظیمات
- فعال/غیرفعال کردن هر شبکه به صورت جداگانه
- طراحی مدرن با رنگ‌های اختصاصی هر شبکه
- باز شدن در پنجره جدید

### 📚 مقالات مرتبط
- نمایش مقالات مرتبط بر اساس دسته‌بندی
- طراحی کارتی و زیبا
- تصویر شاخص، عنوان و تاریخ
- **قابل تنظیم تعداد مقالات**
- **قابل غیرفعال‌سازی از تنظیمات**

### 💬 نظرات با طراحی مدرن
- طراحی سفارشی برای نمایش نظرات
- آواتار کاربران
- تاریخ با اعداد فارسی
- فرم ارسال نظر زیبا
- پشتیبانی از پاسخ به نظرات (Threading)

### 📱 واکنش‌گرا (Responsive)
- طراحی کامل برای موبایل
- طراحی کامل برای تبلت
- طراحی کامل برای دسکتاپ

## 📦 نصب و راه‌اندازی

### مرحله 1: نصب
1. فولدر `beautiful-post` را در `wp-content/plugins/` قرار دهید
2. به پنل ادمین وردپرس بروید
3. از منوی **افزونه‌ها > افزونه‌های نصب شده**، پلاگین را فعال کنید

### مرحله 2: تنظیمات
1. از منوی سایدبار روی **Beautiful Post** کلیک کنید
2. تنظیمات دلخواه را انجام دهید
3. دکمه **ذخیره تنظیمات** را بزنید

---

## 💡 نکات مهم

1. **تصویر شاخص**: برای بهترین نمایش، از تصاویر با کیفیت بالا استفاده کنید (حداقل 1920x1080)
2. **بیوگرافی نویسنده**: برای نمایش در باکس نویسنده، بیوگرافی را در پروفایل کاربری پر کنید
3. **مقالات مرتبط**: مقالات باید حداقل یک دسته‌بندی مشترک داشته باشند
4. **کش**: بعد از تغییر تنظیمات، کش را پاک کنید

---

## 🐛 عیب‌یابی

### صفحه مقاله تغییر نکرده است
- مطمئن شوید پلاگین فعال است
- کش مرورگر را پاک کنید (Ctrl+F5)
- اگر از پلاگین کش استفاده می‌کنید، آن را پاک کنید

### تصویر شاخص نمایش داده نمی‌شود
- مطمئن شوید مقاله تصویر شاخص دارد
- از تصاویر با کیفیت مناسب استفاده کنید

### باکس نویسنده خالی است
- بیوگرافی نویسنده را در **کاربران > پروفایل** پر کنید

### مقالات مرتبط نمایش داده نمی‌شوند
- مطمئن شوید مقاله در یک دسته‌بندی قرار دارد
- مطمئن شوید مقالات دیگر در همان دسته‌بندی وجود دارند
- از تنظیمات، گزینه "نمایش مقالات مرتبط" را فعال کنید
